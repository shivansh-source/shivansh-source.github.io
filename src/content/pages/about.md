I'm Shivansh Sinha, a software engineer focused on cloud-native infrastructure — Kubernetes, distributed systems, and increasingly the tooling that sits between infra and AI systems.

## Background

I contribute across several CNCF-ecosystem projects — mostly bug fixes, CI/infra work, and provider-level features:

**[OpenEverest](https://github.com/openeverest)** — Kubernetes-native database provisioning platform. Merged: a core CI fix ([openeverest#2962](https://github.com/openeverest/openeverest/pull/2962)), namespace-scoped watch fix for the Postgres provider ([provider-percona-postgresql#21](https://github.com/openeverest/provider-percona-postgresql/pull/21)), two Helm chart fixes ([#82](https://github.com/openeverest/helm-charts/pull/82), [#77](https://github.com/openeverest/helm-charts/pull/77)), a CI test job for the ClickHouse provider ([provider-altinity-clickhouse#21](https://github.com/openeverest/provider-altinity-clickhouse/pull/21)), and [a blog post on HA PostgreSQL](https://openeverest.io/blog/ha-postgresql-openeverest/). Currently working on a curated LLM catalog for the KubeAI provider and clickhouse-backup based backup/restore support.

**[KubeStellar](https://github.com/kubestellar)** — multi-cluster Kubernetes configuration management. 12 merged PRs spanning dependency upgrades (Kubernetes 1.32, KubeFlex v0.9.3), CI/E2E test work, repo hygiene, and interactive KillerCoda learning scenarios. Also filed a large batch of detailed bug reports from a systematic review of the Console dashboard.

**[Open Cluster Management](https://open-cluster-management.io/)** — added TLS profile configuration support for spoke cluster agents ([ocm#1486](https://github.com/open-cluster-management-io/ocm/pull/1486)).

**[kro](https://github.com/kubernetes-sigs/kro)** (Kubernetes Resource Orchestrator) — authored [KREP-008](https://github.com/kubernetes-sigs/kro/pull/933), a design proposal for resource-backed `includeWhen` evaluation.

I'm also currently building tools at the intersection of Kubernetes and AI systems.

This site is where I write up notes on infrastructure, Kubernetes internals, and whatever else I'm digging into.
